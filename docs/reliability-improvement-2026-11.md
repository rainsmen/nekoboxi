| 历史数据库迁移 | 保留 1→2→3 手动迁移及后续自动迁移；不使用破坏性回退 | 旧 schema 实际迁移测试 |

备份仍含所选节点及设置的敏感内容，不是加密文件。规则-only 指纹用于一致性校验，不是备份真实性签名。若停止清理失败，恢复与应用内重启会被拒绝；后台进程保留失败任务、统计快照和运行锁，下一次维护请求会重试。统计写入失败可在存储恢复后补写；核心关闭仍报错时不会把重试伪装为成功。如必须强制结束进程，应知晓尚未持久化的流量可能丢失。

## 路由与核心适配

- 路由判空覆盖协议、网络、来源端口等条件；域名与 IP 规则集可以同时保留。
- DNS 派生规则保留来源 IP、来源端口和网络限制。目的 IP、目的端口、自定义 JSON、非 DNS 协议条件不能可靠等价转换时不自动生成 DNS 规则；需要独立配置 DNS 策略，不能假定所有流量规则都有 DNS 等价物。
- 嗅探之后处理 DNS 劫持，再执行解析和用户规则；组播拒绝不再错误要求来源同时为组播。
- 代理链复用已有节点时使用实际标签；编辑和构建均检测循环；构建最多支持 128 层嵌套并明确报错。
- 默认网卡监听有注册/注销确认；单个监听器异常不会终止事件循环。Go 监听注册表覆盖关闭与并发回调。
- DNS 响应支持取消及期限；fd 由调用方拥有，避免关闭后被复用。IPv6 socket 地址与共享 UID 映射已适配。
- HTTP 请求有期限、正文大小限制和竞速失败者清理。日志在写入和导出边界脱敏。
- VPN 与纯代理使用各自的前台服务类型；通知同步进入前台。完整重启等待停止成功，再请求后台退出并等待 Binder 死亡；恢复后的重启失败可回传 UI。
- 连接初始化期间不读取未初始化的 selector 配置。共享节点汇总多个路由 tag 的贡献，历史基数仅加一次；选择器按每条连接实际成员计数；单节点与单成员链保留独立入口标签，Tailscale endpoint 纳入统计。tracker 在核心启动前注册，关闭等待已开始的 I/O 计数结束。
- 包名和 UID 表先完整构建后发布不可变快照；刷新失败保留旧表，首次失败允许重试。原生侧不再吞掉包名查询失败。

## 状态恢复与并发复核补充

- 订阅提交与备份恢复的 ATTACH 使用独立 Room 连接，事务内 DAO 绑定同一连接。`SubscriptionConsistencyTest` 用屏障暂停在 ATTACH 后，验证普通选择及另一恢复均可完成，且 singleton 不包含附加库。此测试不等同于 Android 跨进程数据库全面验收。
- `EditorRecreationTest` 覆盖节点编辑保留脏状态和原配置指纹、分组/路由恢复监听、未修改路由直接保存、备份快照标识随 Fragment 恢复及失效快照不打开目标文件。导出内容保存于应用私有缓存，不塞入大型 Bundle；缓存若被清理，会明确失败并要求重新导出。
- `TrafficStopRecoveryTest` 使用真实 SQLite 写入失败与 Service 重建，验证最终统计事务回滚、保留已读取的计数、重试及运行锁释放。原生计数源与日志使用测试替代，不宣称真实 VPN 或插件故障已实机验证。停止状态清零持独占维护锁，避免新服务读取清零前的基数；统计数据库工作在 IO 线程。
- 分组前置/落地支持嵌套链；仅匹配 DNS 协议的动作保留为 DNS 全匹配规则。Clash TUIC 固定 IP 时保留默认 SNI，显式 SNI 优先。
- sing-box JSON 的 `outbounds` 包装与顶层数组均保留线性 detour 依赖。依赖作为节点内嵌副本保存、分享和备份，生成配置时统一重写标签，并可在节点设置中编辑；修改另一同名节点不会联动。缺失、循环、重名或策略组依赖会拒绝拆分并提示使用完整自定义配置。
- 删除失败保留编辑页并展示原因；保存确认使用动作名称；自动更新间隔明确至少 15 分钟；资产区分未下载与版本未知。
- Preview/Release 在 native job 运行固定版本 actionlint；Release 的 Gradle 与轮换阶段分别传入对应别名密码。

## 2026-11-11 复核补充

- 删除队列按项目携带恢复代次，跨代次批次拒绝提交；节点、分组、规则删除与选择清理共用附加库事务。移动节点也校验代次，旧编辑器不能移动恢复后的同 ID 对象。
- 完整编辑器使用自身固定 ID、草稿归属令牌及页面初始代次；迟到初始化必须在主线程验证归属后才写缓存。错误导航关闭源编辑器，有未保存内容时明确确认放弃；保存拒绝其他编辑页的草稿。
- 订阅先全局匹配唯一内容再匹配名称，支持交换名称和仅重排；sing-box 线性图身份忽略显示标签并规范化 JSON 键顺序。损坏 JSON 尾随内容、缺失字段及不支持的 DNS 依赖不会变成部分替换。
- 格式识别不再因备注包含 `proxies:` 或 `[Interface]` 误判。Clash/Hysteria 保留合法端口范围；WireGuard 省略 MTU 保留默认值，缺失字段提示条目位置。SOCKS 分享保留 4a 协议、空密码、字面 Base64 用户名和空白凭据。
- Tailscale 使用真实 endpoint 作为 selector、路由或链目标，不再用提前截流规则或 direct 包装。自动状态目录按节点、认证信息、恢复代次和链实例隔离；旧共享目录无法可靠归属，不自动迁移，需重新认证。明确指定状态目录的自定义配置由作者负责隔离。
- 停止维护使用独立请求 token、异步命令和非阻塞状态读取；重启也改为带有效期的异步请求，取消或过期的请求不能在主线程恢复后突然退出进程。原生关闭 panic 的错误在重试中保留。
- 资产格式校验进一步调用核心运行规则构造，拒绝无效正则、CIDR 和端口范围；下载完成后核对开始下载时的文件身份，拒绝覆盖期间导入的新文件。部分删除留下的元信息可在重建列表后继续清理。
- 分组导出在系统文件选择器之前固定私有内容快照；复制按实际结果反馈，列表复用时清空旧流量，补充分组菜单可访问名称。资源说明不猜测启用状态，清理重试按钮与实际动作一致，备份提示说明原数据与下一步。
- 正式发布同时校验历史证书与当前证书链，使用临时测试证书构造真实正反例 APK；版本递增在构建前和发布前检查，所有正式发布共用并发锁。签名参数按整套来源选择，避免混用环境变量和本地配置。
