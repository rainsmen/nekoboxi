# ThBox 1.7.0

发布日期：2026-11-12。Android 10+，arm64-v8a；sing-box 1.14.4，Naive 使用内置 NaiveProxy 模块。

## 主要变化

- 修复 Android Wi-Fi 回调异常引发的 JNI 后台崩溃，以及服务断开后的 DeadObjectException、旧连接状态和迟到测速结果。
- 修复 GeoIP 资源被错误拒绝安装、首次启动资源竞争和下载状态显示；增加真实 APK 数据库安装读取校验。
- 分应用设置不再因打开页面而自动启用；模式和名单原子保存，“应用/重载”完整重建 VPN，使取消浏览器绕过等设置可靠生效。
- 停止按钮固定在底部中央，不随列表滚动隐藏；保留主题、动态配色、无障碍与安全边距。
- 恢复 Naive 旧额外请求头兼容，忽略行仅写日志；修复 URI 重复解码。未启用 UoT 时明确 TCP-only，避免错误发送普通 SOCKS UDP 命令。
- 加强备份恢复、订阅替换、节点身份、引用、编辑草稿、排序、批量导入与流量统计的一致性和失败恢复。
- 修复路由/DNS、代理链和多协议分享往返；加强导入内存限制、日志脱敏、Tailscale 状态隔离和停止/重置并发处理。

## 安装与使用

- 附件中的 `ThBox-1.7.0-arm64-v8a.apk` 为正式版，包名 `io.github.rainsmen.thbox`，沿用正式签名轮换链。兼容的旧正式版可直接覆盖安装。
- Preview 包名为 `io.github.rainsmen.thbox.preview`，可与正式版共存。仅装过 Preview 的用户需要通过应用内备份/恢复迁移配置；备份包含节点凭据，请妥善保管。
- 修改分应用设置后点击“应用”，连接会短暂断开并重新建立；通用重载不再只切 selector 节点。
- 本版不擅自调整 IPv6/DNS。服务端没有 IPv6 出口时，应按其能力选择客户端策略；本地网络有 IPv6 不代表代理出口也支持。UDP over TCP 必须有远端支持。

## 验证与边界

发布流程包含 Kotlin 单元测试、lint、Go race、生成配置启动/关闭、APK 内数据库安装读取、JNI 异常处理契约以及最终签名/历史签名链校验。Release 附带 `build-evidence.txt`，记录源码提交、子模块和 APK SHA-256。

Android 12 ART 对照已复现并验证 Wi-Fi JNI 崩溃修复；完整测试范围见仓库 `docs/reliability-improvement-2026-11.md`。这些检查不替代所有手机、远端服务器、切网和长时间后台运行验收。
