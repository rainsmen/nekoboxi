# ThBox 常见问题与排查指南 (FAQ)

本文档汇集了 ThBox for Android 客户端在安装、运行、DNS 分流与系统兼容性方面的常见问题排查建议。

---

## 1. 安装与更新相关

### Q1: 从旧版覆盖安装提示“软件签名证书不一致，需要卸载重装”？
- **原因**：早期版本在 GitHub Actions 云端构建时未指定固定密钥，Android Gradle 插件在每次虚拟机启动时现场生成临时的 Debug 密钥对，导致每次构建出来的 APK 证书指纹完全随机。
- **现状与解决**：
  - 自 **1.5.6+** 版本起，项目内置了版本库级固定发布密钥（`keystore/release.keystore`），后续所有 Releases 与云端构建都拥有永久一致的 SHA-256 证书指纹；
  - **首次升级须知**：若您手机上当前安装的是 1.5.5 或更早的构建版本，由于历史 APK 证书不同，需要**先备份配置并卸载旧版本**，全新安装 1.5.6+ 之后，后续所有版本均可无缝直接覆盖升级。

## 2. 节点连接与运行错误

### Q2: 启动节点提示 `decode config: dns.servers[0]: unknown transport type: rcode`？
- **原因**：此问题见于特定过渡版本中误将 DNS 阻断服务的属性标记为尚未注册的传输类型 `type = "rcode"`。
- **解决**：该问题已在 **1.5.6+** 正式版中彻底修复。请升级至最新稳定版本即可正常连接。

### Q3: 开启 VPN 后网页无法打开，但节点测速正常？
- **排查步骤**：
  1. **检查 DNS 配置**：进入“设置” -> “路由与 DNS”，确认“远程 DNS”与“直连 DNS”均已正确配置。推荐直连 DNS 使用 `local` 或运营商推荐 DNS，远程 DNS 使用主流公共 DoH（如 `https://1.1.1.1/dns-query`、`https://8.8.8.8/dns-query`）。
  2. **FakeIP 兼容性**：若开启了 FakeDNS（FakeIP），部分不支持虚假 IP 回源的国内应用可能异常。可在设置中尝试关闭 FakeDNS，或在分流规则中将这些应用/域名加入“Direct”（直连）。
  3. **绕过局域网**：确认“绕过局域网地址”已勾选，防止局域网打印机、NAS 等连接被截获。

## 3. 系统权限与后台保活

### Q4: 在部分国产定制系统（小米 HyperOS、华为 HarmonyOS、vivo OriginOS、OPPO ColorOS）上后台频繁断连？
- **排查建议**：
  1. **电池策略**：在系统“设置” -> “应用管理” -> “ThBox” 中，将“电池优化”设置为“无限制 / 不优化”；
  2. **自启动与关联启动**：允许 ThBox 的“自启动”和“后台运行”权限；
  3. **后台任务锁定**：在多任务界面下拉锁住 ThBox 任务卡片，防止系统一键清理后台时误杀 `:bg` 代理守护进程。

---

## 4. 自定义规则与外部规则导入

### Q5: 支持哪些规则文件格式导入？
- 自 1.5.6 版本起，在“路由资产（Assets）”页面已支持直接导入以下格式文件：
  - `.db`：传统 GeoIP / GeoSite 数据库文件（如 `geoip.db`、`geosite.db`）；
  - `.srs`：sing-box 官方二进制编译规则集文件（Rule Set Binary）；
  - `.json`：sing-box 纯文本规则集定义。
